# SHOA / CEC2022

Implementacion minima ejecutable de SHOA puro sobre funciones CEC2022.

## Ejecutar

python run_shoa_cec2022.py --functions 1 --dim 10 --pop 20 --max-iter 50 --runs 1

## Salidas

En outputs/run-YYYY-MM-DD-HH-MM-SS/ se generan:

- config_used.json
- runs_raw.csv
- full_output.csv
- summary_by_function.csv
