# SHOA / TMLAP

Implementacion minima de SHOA para instancias TMLAP en archivos txt.

## Ejecutar

python run_shoa_tmlap.py --instances 1.instancia_simple.txt --pop 20 --max-iter 50 --runs 1

## Salidas

En outputs/run-YYYY-MM-DD-HH-MM-SS/ se generan:

- config_used.json
- runs_raw.csv
- full_output.csv
- summary_by_function.csv
